# AWS

## Regions & Availability zones (AZ)
A Region is a cluster of data centers, formed by availability zones.

Major aspects to select a region to deploy an application are:
1. Compliance
2. Proximity (latency)
3. Service availability
4. Pricing

Each region has (at least) 3 availability zones, which are discrete data centers, isolated from disasters and connected with a high BW.

## Scalability & High availability
An application/system is scalable if it can handle greater load by adapting the resources. There are two kinds of scalability:

1. Vertical: Increase the size of the instances. Common for non-distributed systems and limited by hardware limits
2. Horizontal (elasticity): Increase the number of instances. Common for distributed systems.

Scalability is linked but different than high availability. High availability means that the application is in at least 2 data centers (AZ)
