## Rekognition 
Find objects, people, text, scenes in images & videos using ML.

Facial analysis and facial search to do user verification.
Content moderation: Detect content that is inappropriate or unwanted -> create a safe user-experience (set a minimum confidence threshold). Can be combined with manual review w/ Amazon Augmented AI (A2I).

## Transcribe
Convert speech to text using deep learning process (ASR)

1. Automatically remove PII(personal identifiable information).
2. Automatic lang identification.

## Polly
Turn text into speech. 

Lexicon: Customize the pronunciation of words/acronyms.
SSML: Speech Synthesis Markup Lang -> more customization.

## Translate
Natural & accurate lang translation. Used to localize content (websites)

## Amazon Lex & Connect
Same technology that powers Alexa. Helps build chatbots, call center bots

Amazon connect: Create callcenters, uses Lex in streaming.

## Amazon Comprehend
Fully managed & serverless service for Natural languague processing (NLP).

Comprehend medical detects & returns useful information in unstructured clinical text.

## SageMaker
Fully managed to build ML models. Helps in the process of data labeling, building,training & tunning and deploy the model.

## Kendra
Fully managed document search service powered by ML.
Also can use incremental learning from the interactions from the user.

## Personalize
Fully managed ML service to build apps with real time personalized recommendations.

## Textract
Extract text, handwriting from any scanned document using AI & ML.
